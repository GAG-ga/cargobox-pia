Registrar avance del paquete US04

No se pudo entregar US05

Si es el segundo intento, el paquete se guarda en el centro de distribución. (RN-06)

Registrar entrega US06 / US07 / US10

Se necesitan la firma, una foto del paquete entregado y el nombre de quien recibe. (RN-07)

Programar nueva visita US10

El repartidor vuelve a intentar la entrega. Solo se puede una vez y dentro de 5 días hábiles. (RN-13)

Corregir direcciones US03

Solo antes de que el paquete se clasifique. Si corriges una dirección, llena su calle y su código postal; deja en blanco la que no cambia. (RN-10)

Cambiar dirección de entrega US11

Disponible mientras el paquete va en camino. Tiene un costo de $80 y el envío pierde la garantía de fecha. (RN-14)

Cancelar envío US02

Solo mientras el paquete no se haya clasificado. (RN-09)

Declarar paquete perdido US15

Se usa cuando el paquete lleva más de 10 días sin movimiento. Se calcula una compensación según el valor del contenido. (RN-18)

Reportar paquete dañado US14

Adjunta una foto del daño. Se abre un folio para el supervisor de la sucursal. (RN-17)

Historial de movimientos US09

Por seguridad, solo se muestra con el teléfono de quien envió el paquete. En la demo es 8112345678; con otro teléfono la API responde AccesoDenegado (RN-08).
